# Crystal Protectors

A 2D pixel art game inspired by Dungeon Defenders, made in Godot 4.7.

**Play in the browser:** https://megalodooon.github.io/crystal-protectors/

Controls: WASD to move, left mouse to attack, Q to switch weapon, 1-7 for a new weapon of that rarity, E to level up, R to upgrade rarity (at max level), C to raise combat level, G to start the next enemy wave, V to show the weapon attributes, X to reroll them.

The web build is exported and deployed automatically by GitHub Actions on every push to `main`.
